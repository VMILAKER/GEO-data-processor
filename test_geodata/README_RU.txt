ТЕСТОВЫЕ ГЕОГРАФИЧЕСКИЕ ДАННЫЕ
Все значения синтетические, не реальные наблюдения.
Профили: 2 станции, по 3 глубины (0,10,20 м), 6 наблюдений.
Сетка: 2 широты x 3 долготы, WGS84, температура в градусах Цельсия.
CSV, TSV, JSON, GeoJSON, KML, KMZ, GML, Shapefile, Parquet и ODV TXT: профили.
GeoTIFF, NetCDF classic и Zarr v2: сетка.
В GeoTIFF верхний левый угол 17.75E,59.75N, шаг 0.5 градуса; координаты центров совпадают с NetCDF.
В KML высота точки 0; глубина измерения хранится в ExtendedData.
Shapefile содержит 6 точек: глубины одной станции имеют одинаковые координаты. Не разделяйте SHP/SHX/DBF/PRJ/CPG.
GML использует прикладное пространство имен urn:test:geodata; это не файл стандартного океанографического продукта.
Zarr — каталог; скрытые файлы .zarray/.zattrs/.zgroup обязательны.
profiles_odv.txt: подготовленная таблица для проверки импорта в ODV. Сам ODV в среде не запускался; может потребоваться сопоставление столбцов в диалоге импорта.
ВАЖНО: grid_classic.nc и grid_netcdf.cdf — NetCDF classic, НЕ NetCDF-4 и НЕ NASA CDF.
Не созданы в этой среде: HDF5, NetCDF-4, NASA CDF, GRIB2 (нет библиотек записи).
Для их создания на своем компьютере выполните в распакованном каталоге:
python -m pip install -r requirements_additional.txt
python generate_additional.py
Скрипт GRIB2 создает поле температуры воздуха на 2 м в K — проверка декодера, не океанографический параметр. Профильные файлы содержат температуру воды в degC.
Расширения .grib/.grb, которые создаст скрипт, содержат редакцию GRIB2.
Не включены: неизвестные .nce/.jos/.var, PostGIS (сервер), нативная коллекция .odv.
